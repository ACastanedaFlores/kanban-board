# 📋 Kanban Board - Vanilla JavaScript

Un tablero de gestión de tareas dinámico y funcional construido para practicar lógica de programación, manipulación del DOM y persistencia de datos.

## ✨ Características
* **Sistema CRUD:** Permite crear, leer, actualizar el estado y eliminar tareas.
* **Interfaz Interactiva:** Las tarjetas se mueven entre columnas de forma lógica.
* **Persistencia con LocalStorage:** Las tareas se guardan en el navegador; no se pierden al recargar la página.
* **Diseño Limpio:** Maquetado con CSS Grid y Flexbox.

## 🛠️ Tecnologías Utilizadas
* **HTML5:** Estructura semántica.
* **CSS3:** Diseño responsivo y moderno.
* **JavaScript (Vanilla):** Lógica pura sin librerías externas.

## 🚀 Cómo usarlo
1. Clona este repositorio.
2. Abre el archivo `index.html` en tu navegador favorito.
3. ¡Empieza a organizar tus tareas!
